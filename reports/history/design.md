## design-system/cczj-video/MASTER.md

<a id="origin-master--cczj-video-移动端设计规范"></a>

### CCZJ Video 移动端设计规范

更新：2026-10-18。适用 Vue / Wails Android 移动呈现，不改变桌面端或已保存的主题数据。

<a id="origin-master--设计依据"></a>

#### 设计依据

用户认可既有桌面视觉，要求移动端与之协调。移动端保留同一套图标、主题色、字体偏好和按钮语义，移除重复大标题、大片灰蓝色蒙层和笨重色块。产品名称只有 CCZJ Video，页面直接描述采集、搜索、收藏、下载、历史和设置等实际功能。

`ui-ux-pro-max` 视频产品检索中可采纳的原则是内容与海报优先、保留继续观看、强调色克制。自动生成的黑底红色 OTT 配色、营销 Hero 结构及外部字体不符合用户现有主题，未采用。触控、可读性和 Vue 实现指导作为检查依据，不能替代实际截图评审。

<a id="origin-master--颜色与背景"></a>

#### 颜色与背景

- `bgInput`、`textPrimary`、`textSecondary`、`btnSolid`、`btnSolidText` 和强调色来自现有主题；输入背景不能再错绑成卡片背景。
- 有壁纸时，阅读表面为浅色白 91% 或深色 `#181b20` 92%。顶底导航采用相应中性色 80% 不透明度和 10px 模糊；移除硬分隔线，顶部通过 12px 渐变与内容衔接。壁纸仍可见，背景叠白 30% 或黑 24% 的中性遮罩。
- 无壁纸时采用原主题表面。以上变化只用于移动显示，不回写主题设置。
- 强调色用于主要动作和选中标记，禁止将所有层级染成同一颜色。常规文字对比度至少 4.5:1；必要图形和状态标识至少 3:1。透明表面按合成后的颜色检查。

<a id="origin-master--页面结构"></a>

#### 页面结构

- 首页、搜索、收藏、历史、设置五个主页面不渲染顶部标题栏，内容从顶部直接开始；底栏直接打开设置目录，常用管理工具合入目录，不增加中转页。
- 详情、设置分组及其他次级页面保留返回入口和单行 16px 标题。顶栏约 56px，图标视觉 19–22px，触摸区 48px；不加大面积图标底色。
- 底栏维持五个已有入口，标签至少 11px；选中文字使用高对比正文色和字重，图标使用主题色，不使用宽胶囊色块。
- 页边距 16px，常规区块间距 20px，阅读卡片圆角 14px，控件圆角 8–12px。现有桌面字体偏好保持生效。
- 文字不直接压在高饱和壁纸人物上：推荐分组、结果、空状态等提供局部可读表面。避免为所有小元素重复套大卡片。

<a id="origin-master--关键页面"></a>

#### 关键页面

- 首页：海报是首屏主体，400px 以下宽度采用 280px 高度，下一栏目可见。移动轮播取消单独“查看详情”按钮及圆点指示器，整张图片为带可访问名称的入口；滑动不能触发跳转。`object-position: center 20%` 优先展示海报上部，仍采用 cover，因此不同宽高比下会存在裁切。推荐标题 16px，说明另起一行、12px，层级低于标题。继续观看移除操作在卡片信息区有可见入口，不遮挡画质标记。
- 搜索：单层输入框，输入字体 16px，焦点反馈在整个搜索框外沿。来源与源搜索在次行；搜索历史标题和管理入口在上方，词条在下方换行。常态词条只搜索，不显示删除 X 和清空；管理时选择记录，再通过确认弹窗删除，原生返回先取消确认，再退出管理。
- 收藏：新建为次要动作，收藏夹为轻量横向标签；空状态使用 SVG 星标、局部阅读面板和明确操作，不重复堆叠说明。
- 历史：移动端以长按记录进入管理并选中该条记录，常态不显示管理按钮；滚动或取消触摸应中止长按，松手不打开详情。保留操作提示及管理模式的完成、全选、删除操作；原生返回先退出管理。选中卡片维持可读表面，避免低对比文字压在壁纸上。
- 详情与播放器：保留已完成的海报并排信息、16:9 竖屏视频、下方切源和选集、触控菜单、全屏和返回行为。

<a id="origin-master--内容密度与触摸反馈"></a>

#### 内容密度与触摸反馈

- 继续观看在首页和搜索推荐中使用 56×84px 海报的横向信息行，显示片名和观看集数；首页不再用半列大海报留下大片空位。其他推荐仍使用海报网格。
- 首页移除继续观看记录需要确认，文案说明同时影响观看历史；取消保留记录。离开首页关闭此确认。
- 历史先显示搜索，再显示统计和简短长按提示；海报 64×96px，徽标采用中性次要表面，信息层级低于片名。
- 设置目录的常用工具使用 68px 起的整行入口，图标、名称、说明、箭头沿同一网格排列；工具区接在显示与体验分组后，保留所有现有管理功能。
- 图片上的画质标记采用小尺寸深色半透明背景和白字，避免大块强调色压住海报；空收藏夹不重复显示已选文件夹名称。
- 点击反馈使用轻微缩放与既有 motion token；移动触摸不保留桌面悬停导致的抬升、海报放大、播放遮罩和变色。

<a id="origin-master--验收"></a>

#### 验收

检查真实 MuMu 页面和控件边界，覆盖 320 / 360 / 412 / 768px；比较有壁纸与无壁纸、深浅模式、文本放大和减少动画。截图中检查标题、说明、表面层次、焦点和空状态。播放、横屏全屏及原生返回必须回归。几何检查通过不能作为视觉通过的唯一证据。

生产样式遵守 `cczj-mobile-*` 边界；动画复用项目现有 motion tokens，只优先使用 transform / opacity，不新引入动画依赖。

<a id="origin-master--播放器手势与控制层补充"></a>

#### 播放器手势与控制层（补充）

首页可保留一个 44px 的轻量搜索入口，用于补足页面起点；不恢复重复的大标题或通栏品牌头。轮播采用统一 Pointer Events，拖动跟手、松手按阈值切换，短拖回弹；滚动与图片点击不可冲突。

小屏播放器底部动作仅播放、画中画、全屏，另保留返回、进度条与播放时间；紧凑续播浮条不遮住中央画面。全屏保持一行重点控制，辅助功能集中到右上角三个点的「更多」菜单；窄横屏继续收起次要按钮。左中锁屏、右上 DLNA 投屏，返回优先关闭当前操作层。横向滑动预览并在释放时提交进度，左侧纵滑亮度、右侧纵滑媒体音量；反馈只在手势期间短暂出现。原生亮度只作用于当前窗口，离开播放器恢复。

<a id="origin-master--首页衔接与设置10-月-18-日"></a>

#### 首页衔接与设置（10 月 18 日）

首页不增加通栏标题，搜索入口和海报背后用当前主题的中性色向透明渐变，高度 160–240px，衔接壁纸。设置目录采用带短说明的分组行，基础设置通过四个轻量标签一次显示一类选项；子设置页只保留顶部返回，隐藏底栏和重复返回行。移动端不展示 Windows 字体、窗口或移动布局未使用的网格选项。

设置的开关、数字加减、主题编辑颜色选择和底部操作采用至少 44px 触摸区。豆瓣队列采用记录卡，编辑弹窗减少重复内边距并隐藏滚动条。播放器的控制层采用 motion token 驱动的轻微侧向位移与淡入淡出，幅度为零时保留淡入；关闭总动画、弹层动画或系统减少动画时停止过渡。

移动路由前进从右侧进入，返回反向退出；新旧完整页面同时过渡，顶栏和底栏随页面运动，不先淡空。离开页面保持自己的路由快照与布局，防止提前显示新分组；减少动画和页面动效开关继续生效。目录与分组分别保存滚动位置，快速切换后只留下当前页面。

### 小说模式设计目标

2026-10-21 两端适配：桌面“随手翻”改为书架右侧的竖向书页，手机保留横向卡片。两端删除圆形箭头，通过露出的下一本封面换书，保留键盘焦点和减少动画设置。见 [侧页调整记录](../novel-sidepage-2026-10-21.md)。

2026-10-21 视觉细化：换书页签贴合封面，分类使用纸色滑块并去除上下横线；搜索框、分区编号、封面托影与手机首屏同步整理。见 [界面细化记录](../novel-polish-2026-10-21.md)。

2026-10-21 后续调整：删减宣传性文案，阅读桌改为可轮换真实作品的“随手翻”书堆；增加分类游标、书架入场与封面轻启。最新录屏和分环境验证见 [动效调整记录](../novel-motion-2026-10-21.md)。

2026-10-21 小说首页改为真实源书城，采用纸色、棕墨、宋体标题和主题书架。最新实现、实际数据截图和分环境验证见 [书城交付记录](../novel-bookcity-2026-10-21.md)。任务及验收依据见 [阅读整改任务书](reading.md#origin-reading-redesign)。

- 2026-10-21 用户修订：默认书城，支持未输入书名时浏览真实源的分类与作品列表；书架与设置为其他主入口。搜索位于书城顶部。详见 [小说优先方案](reading.md#origin-novel-first-plan-2026-10-21)。
- 搜索展示书名、作者、来源和简短简介；仅展示真实存在的元数据，不把书架内容包装为编辑推荐。
- 详情突出继续阅读和可搜索目录。没有真实分类、榜单或推荐能力时，不搭建空的书城模板。
- 阅读器以正文为中心，支持分页和滚动、字号、行距、页边距、字体及阅读主题。主题尊重用户偏好，不能强制覆盖全局配置。
- 用章节身份和文本锚点恢复进度。排版与视口变化后保持阅读段落，不能只保留旧页码。
- 左上角返回回到本次进入阅读的位置，保留搜索、筛选和列表滚动；查看书籍详情另设明确动作。
- 空状态只给原因与下一步。正文不堆叠源状态公告、装饰横幅和操作教程。
- 复用基础组件与主题语义，小说信息布局独立于漫画。触摸目标至少 44px，键盘、焦点、文本放大和减少动画可用。
- 320/360/412/768px 与 1280/1440px、深浅主题、真实内容、离线及返回恢复分别验收。

<a id="origin-comic--漫画模式设计目标"></a>

### 漫画模式设计目标

2026-10-21 用户恢复漫画设计：采用冷白、莓粉和淡紫，杂志标题、网点与轻微倾斜的封面框构成独立视觉。主入口为“漫游 / 追漫 / 设置”，搜索位于顶部；漫游接入崩坏3、泰拉记事社真实官方书目，追漫只展示个人收藏与历史。设计调研、截图和浏览器/Android 原生验证见 [漫画放映室记录](../comic-room-2026-10-21.md)。以下旧目标保留其阅读与资源契约。

2026-10-20 重写；2026-10-21 前端结构与视觉已落地，浏览器验证结果见 [整改记录](../reading-redesign-2026-10-21.md)。原生端及未实现能力仍待验收。任务及验收依据见 [阅读整改任务书](reading.md#origin-reading-redesign)。

- 默认漫游，以真实封面与作品专区浏览为中心；追漫负责个人收藏与继续阅读。只有来源提供真实更新信息时才显示未读话数。
- 搜索与详情突出真实封面、作品来源和话列表。仅在有真实更新数据时展示更新流，不把本地书库包装成外部发现。
- 阅读器分别处理条漫与单页，支持 LTR/RTL、适宽/适屏及缩放；缩放平移不能误触翻页。
- 每张图片独立呈现加载、失败与重试，保留占位，补载不挤走当前页；优先当前页，限制预取并释放远离视口的资源。
- 进度使用稳定话与页身份及页内位置。图片请求保留所需 Referer、Cookie 和声明请求头，正确隔离缓存。
- 左上角返回回到本次入口并恢复书库/搜索位置，查看漫画详情另设动作；切话不累积返回层级。
- 无数据的更新数、评分、推荐和分类不显示。源管理从主阅读内容中移出，诊断信息按需展开。
- 共用基础组件和主题语义，漫画布局及交互不套小说模板。触摸目标至少 44px，键盘与焦点可用，尊重减少动画设置。
- 320/360/412/768px 与 1280/1440px、深浅主题、横竖屏、长图/单页、部分图片失败与原位返回分别验收。

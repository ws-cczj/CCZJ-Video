# CCZJ 公共样式复用整改

日期：2026-10-20。范围为项目构建中的 Vue、全局 CSS、视频/小说/漫画及移动端样式，还有公共 UI 控件。保留工作区原有的其他改动，没有提交、推送或发布。

## 查到的问题

1. 公共库已经由 `main.ts` 加载，问题发生在使用侧：274 个公共类中，只有 27/134 个 Vue 文件在模板中引用。基础 Button、Modal、Select、Spinner、Empty 等组件也自己重复维护布局和基础样式，页面复用这些组件时仍没有复用公共定义。
2. 组件 scoped、模式前缀、响应式及状态规则大量存在，直接把声明搬到模板类会改变选择器优先级。原来没有让这些规则引用公共定义的构建机制，结果公共库与业务 CSS 各自维护。
3. Modal 内部复制了一套按钮 CSS 和加载行为；NumberField 没有从公共组件入口导出。Modal 还要求额外开启 `showFooter` 才显示调用方的 footer 插槽，造成部分编辑弹窗没有保存按钮。已用浏览器测试先复现该问题，再修复。
4. 补全生成器用正则解析 CSS，带转义点号的 `cczj-h-1.5` 会被截断；生成文档没有同步检查。历史尺寸类还混合了固定像素与 4px 单位命名，容易凭名字误用。

## 已整改

- 9 个基础 UI 组件的 78 处简单布局声明移到模板，直接使用现有 CCZJ 类。Modal 的默认按钮统一使用 Button，加载时保持宽度并禁用重复提交；自定义 footer 正常显示。补齐 NumberField 的公共导出。
- 104 份样式的 7,028 处相同声明改为 `@apply cczj-*`，直接读取现有 `cczj-utilities.css`。覆盖 App、公共组件、设置、源管理、播放器、移动布局以及小说、漫画样式。作用域、复杂选择器、媒体条件、状态和声明顺序保留在各业务模块中。
- 新增本地 PostCSS 组合插件，运行时产物仍是普通 CSS。公共定义变动会更新消费者；未知类、条件类误用及选择器外组合会使构建失败。PostCSS 8.5.30 原已由 Vite 安装，本轮把它列为明确的开发依赖，版本未升级。
- 公共库的 274 个类保持兼容。尺寸单位按现有定义保留，生成手册展示实际值，避免改动旧类后影响页面尺寸。
- 生成器改用 CSS AST，包含转义类名和条件类，新增 CSS 指令提示；同步 HTML 补全和速查手册。完整检查会验证生成文件是否过期，以及构建产物中是否遗留未展开的组合指令。
- 增加可重复执行的统计命令和[使用文档](../docs/cczj-styles.md)。扩展包运行时注入的 CSS 保持普通 CSS，应用构建中的组合语法不用于运行时注入。

## 统计

来源：[整改前](css-reuse-2026-10-20/before.json)、[整改后](css-reuse-2026-10-20/after.json)。统计识别公共库中实际定义的类，不把业务类名的 `cczj-` 前缀算作工具库使用。

| 指标 | 整改前 | 整改后 |
| --- | ---: | ---: |
| 公共工具类 | 274 | 274 |
| 模板直接引用的 Vue 文件 | 27/134 | 36/134 |
| 自身模板或 CSS 直接引用公共库的 Vue 文件 | 27/134 | 74/134 |
| CSS 组合复用的样式文件 | 0 | 104（63 个 Vue 样式、41 个 CSS 文件） |
| 被引用的公共工具类 | 142 | 240 |
| 与公共库定义相同的重复字面声明 | 7,115 | 87 |

Vue 自文件统计不包括通过外部样式、模式外壳和公共组件间接使用公共库的页面。保留的 87 处匹配值均为动画系统及关键帧中的透明度声明。批量组合迁移逐份比较展开后的 CSS AST，104 份的选择器、条件、声明顺序和值完全等价，见[迁移证据](css-reuse-2026-10-20/migration-equivalence.json)。随后基础组件的模板迁移与弹窗整合单独经过界面回归。

构建期组合会在各选择器中生成相应声明，本轮统计衡量源码定义的集中复用，不能把重复字面声明减少量等同于产物体积减少量。

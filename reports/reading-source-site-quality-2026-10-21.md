# 交接候选源的内容价值与站点质量复核

日期：2026-10-21。范围：从完整候选库中挑选与中文小说、轻小说、同人、传统图书、中文漫画相关的 16 个站点，检查站点自身页面、公开响应及扩展作者源码。目的是判断哪些值得用、值得修，哪些应放弃；不是重复统计候选数。

本轮没有安装扩展、执行上游规则脚本、绕过登录或付费，也没有修改实现、用户源开关与书架。当前项目适配状态取自 `dist/reading-source-inventory-20261021/source-inventory.json`；站点页面由联网工具与本机普通 HTTPS 请求补充核对。主任务同期完成的 47 项规则深审计在 [正文与图片抽检原始结果](reading-source-content-audit-2026-10-21.json)。页面能打开、扩展存在、项目能解析、整书能读完，是四件不同的事。

## 可以先据此做的选择

**小说值得扩展的不是更多同质转载站，而是补齐内容差异：SF 轻小说负责二次元原创，刺猬猫负责宅文和同人，晋江负责言情与衍生，九九藏书负责传统图书。**它们的选题价值明确，但当前规则或阅读限制不同，不能直接标成“已可完整阅读”。起点的作品资料、分类和榜单也值得接，但付费作品应清楚显示试读/订阅边界。

**漫画建议先保留咚漫作可用的条漫主入口，优先评估快看补国漫、哔哩哔哩漫画补日漫与国漫，漫画柜作为综合日漫备选。瓜子只宜暂作备用。**瓜子链路读得通，但本轮发现其首页章节标记与作品详情明显矛盾，不能再仅凭此前的连通性分数把它定为高质量默认源。

|---|---|---|

| 刺猬猫 | 宅文、同人、游戏/动漫衍生 | **优先适配公开内容**；订阅作品不能当免费全文源 |
| 话本 | 同人、影视/特摄衍生、对话体 | **兴趣备用，修好规则再启用**；正文需要保留说话人和插图 |
| 起点 | 综合男频、长篇、完本、榜单 | **优先适配发现/试读**；强内容库，付费边界明确 |

| 九九藏书 | 传统出版图书、推理、外国文学、古典 | **优先适配评估**；很适合“逛图书馆”，正文正确性还需验证 |
| 咚漫 | 中文条漫、韩漫、恋爱/校园/悬疑/奇幻 | **采用公开章节，作为当前主入口**；收费/客户端章节单独标识 |
| 快看 | 国漫、恋爱/古风/校园、原创条漫 | **优先适配**；比再加一个同质转载站更能增加内容差异 |
| 哔哩哔哩漫画 | 日漫、国漫、韩漫分类及正版热门作品 | **优先适配发现/免费章**；不能把商业漫画全部算可读 |
| 漫画柜 | 页漫、日漫及多地区漫画、细分类 | **综合备用，值得专门适配**；目录、页图逻辑不属于普通 CSS 规则 |

| 动漫之家旧条目 | 原本的漫画/轻小说垂直资源 | **搁置当前旧地址**；当前连接证据不足，不能凭历史名气推荐 |

“优先适配”是内容价值判断，并不等于今天导入即可用。没有为这些站打文学质量分；分类丰富、正版来源、可见更新、可读范围、元数据和正文正确性分别记录。

## 小说逐站复核

### 1. 番茄小说：发现内容丰富，完整阅读不能一概而论

- **内容定位**：官网同时提供男频、女频精选和最近更新，覆盖都市、玄幻、历史、悬疑、科幻、现言等；适合当前书城的基础浏览。[官网](https://fanqienovel.com/)
- **更新与资料**：官网能列出具体最新章节、作者与更新时间，具备做书城与追更的资料基础；不能把首页有推荐等同于所有正文开放。[官网最近更新](https://fanqienovel.com/)
- **限制与适配**：库存的内置适配条目历史链路通过。主任务本轮补测《部族荣光》351 章目录，首章可读，第 176 与 351 章返回订阅/官方客户端权限提示，故应标“公开章节可读，部分章节受限”。详见本轮主任务的正文抽检结果，不能继续沿用“100 分就能读完整书”的解释。
- **建议**：保留为发现主入口，遇到受限作品明确提示可读范围；不以其替代有完整内容实测的阅读源。

### 2. SF 轻小说：最值得补的原创轻小说库，问题主要在旧规则

- **内容价值**：官网直接提供魔幻、玄幻、科幻、校园、游戏、同人等分区，作品有作者、字数、收藏；能明显补充现有偏综合网文的书城。[官网](https://book.sfacg.com/)
- **阅读边界**：《血姬小姐才不会被骗》的作品页明确区分最新 VIP 章节和最新公众章节；不应把 VIP 预览当完整正文。[作品页](https://book.sfacg.com/Novel/689943/)、[VIP 章节入口](https://book.sfacg.com/vip/c/9985410/)
- **当前规则**：库存那条“兼容”规则只有历史搜索部分通过，详情没有书名、目录为空；其他变体因 `&&`、脚本/JSON 规则等未转换。主任务进一步确认有选择器转换缺陷。这是适配质量差，不能据此判定 SF 的内容差。
- **建议**：优先单独适配 HTTPS 正式站，分别保存公众/VIP 状态；把搜索、简介、目录、正文逐段验收后再给用户启用。

### 3. 刺猬猫：同人和宅文辨识度强，付费边界很具体

- **内容价值**：站点设有宅文强推、同人强推、科幻无限、游戏竞技、免费同人等入口，适合二次元读者。[首页](https://wap.ciweimao.com/)、[分类](https://wap.ciweimao.com/category)
- **直接抽样**：本机请求《我，救世组织神秘领袖》作品页得到完整章节列表，订阅弹窗明确显示需购 557 章，购买起点为第四十四章，止于第六百章。可见资料与目录充足，但绝非整书免费。[作品页](https://wap.ciweimao.com/book/100255662)
- **当前规则**：库存均未适配，包含 `wap.ciweimao.com1`、`wap-test.ciweimao.com` 等可疑旧/测试地址，也有正式域名；先剔除明显错误地址，再评估正式站。没有执行规则中的脚本。
- **建议**：优先做正式站发现、免费同人和公开章；收费章显示订阅边界，不把订阅提示抽成小说正文。

### 4. 话本：同人有价值，但纯文本提取容易破坏阅读

- **内容定位**：官网推荐包含影视、KPL、特摄、动漫等衍生；对话体是其明显特色，适合特定兴趣读者。[官网](https://www.ihuaben.com/)、[对话小说分区](https://www.ihuaben.com/category/duihuaxiaoshuo/)
- **正文样本**：《假面骑士：爱与和平》详情列 528 章；公开章节同时含角色姓名、头像、叙述、角色对话和段评。若简单对整个正文容器取 text，段评会混进正文，角色头像/说话人关系也会丢失。[详情](https://www.ihuaben.com/book/12151828.html)、[样本章](https://www.ihuaben.com/book/12151828/73784542.html)
- **当前规则**：库存那条兼容规则仅历史搜索通过，详情和目录失败。本站内容偏好不能概括为整个小说库的精品标准；当前不能作为已可用主源。
- **建议**：兴趣备用。修复时必须专门处理对话块、插图与段评，验证末段和章节导航，不只修到能搜出书名。

### 5. 起点：综合长篇资料质量高，适合发现与试读

- **内容价值**：官网有分类、排行、完本、免费和限免频道，作品资料可提供作者、字数、状态、章节数量；对综合网文书城很有补充。[官网](https://www.qidian.com/)
- **阅读边界样本**：《悟性满级：剑阁观剑六十年》页面标完本、签约、VIP，共 1113 章，其中正文卷 94 章标免费。目录数量不能直接当可读章数。[作品与目录](https://www.qidian.com/book/1032832749/)
- **当前规则**：库存多条变体都未适配，包含脚本头、模板及复合规则差异；不能随机挑一个带“修复”字样的名称导入。
- **建议**：优先适配作品发现、榜单、免费与试读；全文阅读要按实际登录/订阅能力承诺。本轮未验证已购内容接入。

### 6. 晋江：最能补齐女性向与衍生方向

- **内容价值**：第一方移动页明确区分古言、现言、纯爱、衍生、无 CP、百合，还有完结、免费、中短篇；不是另一个男频换皮库。[移动首页](https://wap.jjwxc.net/)
- **阅读限制**：官方订阅说明明确 VIP 章节需要晋江币，且价格按读者等级和章节条件计算；免费入口与 VIP 内容应分别呈现。[订阅说明](https://wap.jjwxc.net/help/explain)
- **当前规则**：库存有网页、WAP、App 多版本，均因脚本 URL、JSON/复合规则等未适配；其中一些条目的源地址只是标签文本，不能作为正常站点地址。
- **建议**：优先适配发现/免费章。正文除目录完整性还应验锁章、修文、作者有话说等边界。本轮没有逐书正文抽样，不能宣称这些处理已完成。

### 7. 书旗：品牌值得评估，库存里的域名不能混用

- **正式站身份**：官方服务协议列出 `www.shuqi.com`、`t.shuqi.com` 等；本机请求这两个入口均返回 200，并能看到男女频、书库、分类等内容。[官方协议](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_other/suit_bu1_other202009181421_79060.html)、[移动官网](https://t.shuqi.com/)、[桌面官网](https://www.shuqi.com/)
- **发现的旧条目问题**：库存有 3 条名叫书旗但指向 `https://www.shuq.net/`。本机请求得到 `301 → https://www.762pk.com/ → 403`。这足以否定“按书旗品牌名就推荐此规则”，但不能仅凭重定向断言该域的所有权或恶意性质。[旧域](https://www.shuq.net/)
- **当前适配**：库存官方 `t.shuqi.com` 条目仍因 JSON 规则未适配。未验证目录、正文、广告或完整书籍可读范围。
- **建议**：搁置 shuq.net 旧条目，仅将官方域作为备用适配候选；先验真实正文，再与番茄、酷我、阅友比较重复程度。

### 8. 七猫：值得留，但内容增量比轻小说/传统文学小

- **内容定位**：官网有男女频原创及都市、玄幻、历史、古言、年代等分区，也有榜单与改编作品入口；具备做浏览库的内容基础。[官网](https://www.qimao.com/)
- **质量边界**：网站“全本免费”的品牌文案不代表本项目通过匿名请求就能获得每章全文。本轮没有验证章节 API、阅读 token、广告/客户端限制。
- **当前规则**：库存以 `api-bc.wtzw.com` 等 API 变体为主，脚本 URL 未适配；不能用“能打开官网”代替验证这些旧 API 规则。
- **建议**：放在备用适配队列。应先补 SF、晋江、传统图书等当前欠缺的类型，再增加与番茄题材相近的大站。

### 9. 九九藏书：最贴近“图书馆”内容，但需验证正文秩序

- **内容价值**：站点分类含外国小说、侦探推理、历史、科幻、散文、国学古籍、古典文学等；主页能见东野圭吾、林语堂、梦枕獏等作者，适合传统图书区。[首页](https://www.99csw.com/)、[图书分类](https://www.99csw.com/book/index.php?type=%E5%A4%96%E5%9B%BD%E5%B0%8F%E8%AF%B4)
- **资料样本**：《解忧杂货店》有作者、译者、标签和按章分节的目录，这类“章—节”层次比只按数字排序更值得保留。[作品与目录](https://www.99csw.com/book/5684/index.htm)
- **当前规则**：库存未适配，其中一条 `a.2` CSS 选择器无效，另一条目录需要模板能力。没有逐节验证正文排序、缺段、错字、插入站名，本轮也未判断作品授权状况。
- **建议**：优先评估传统图书适配价值。首、中、末节与原网页逐段比对通过后才纳入默认阅读库；目前仅能确认内容定位有吸引力。

## 漫画逐站复核

### 10. 咚漫：当前最适合保留的条漫主入口

- **内容差异**：第一方首页按星期组织连载，同时提供恋爱、校园、悬疑、奇幻、治愈、少年等内容；比仅两个游戏专题更适合日常逛漫画库。[官网](https://www.dongmanmanhua.cn/)
- **范围限制**：官网有登录和咚币充值入口，不能把所有作品和章节都标免费。[官网](https://www.dongmanmanhua.cn/)
- **现有证据**：主任务同期对《神之塔外传：乌雷克·马奇努》和《神之塔》各取首、中、末位置共 6 话，页列表和图片样本能获取，样图宽 690 像素；首部作品的第 1 话还抽验了首、中、尾图。随后直接核对《神之塔》原站两页公开列表，共 12 项（含预告、第 1～10 话），与当前适配一致，本例未发现漏跟第二页；但这不代表整部长篇全本。证据见 [本轮深审计](reading-source-content-audit-2026-10-21.json)和[公开目录核对](dongman-directory-quality-2026-10-21.json)。
- **建议**：作为当前公开章主入口保留。按具体作品记录公开可读范围；长条图按顺序与原站比对，并单测非首话、收费话和已完结作品。

### 11. 快看：扩充国漫的优先候选

- **内容价值**：官网将恋爱、古风、大女主、穿越、校园、玄幻、悬疑、奇幻等分类放在首层；有《非人哉》《白日梦我》《我独自升级》等不同方向作品，补库价值明确。[官网](https://www.kuaikanmanhua.com/)
- **可见细节**：《错撩》详情返回章节数据；原始页面中存在 `is_pay_comic`、`need_vip`、`locked`、`is_free` 等字段，说明接入时应保留可读性，不应只提取章节 URL。[作品页](https://www.kuaikanmanhua.com/web/topic/21881/)
- **适配成本**：扩展作者的固定版本源码通过 `api.kkmh.com` 搜索、Nuxt 页面资料和章节阅读页提取图片；项目不能直接导入 Kotlin 扩展。本轮仅阅读源码，没有执行其中的 QuickJS 解析。[扩展源码](https://github.com/keiyoushi/extensions-source/blob/314a0d1b2b6b194f6a4f9aee252fec9ce55ae5ca/src/zh/kuaikanmanhua/src/eu/kanade/tachiyomi/extension/zh/kuaikanmanhua/Kuaikanmanhua.kt)
- **建议**：优先专门适配。先验证公开章的图序、实际尺寸及末话限制，再决定是否成为默认入口。

### 12. 哔哩哔哩漫画：最有价值的日漫/国漫补充之一

- **内容价值**：第一方首页分日漫、国漫、韩漫榜，能看到《航海王》《名侦探柯南》《间谍过家家》《迷宫饭》等页漫，也有国漫作品，明显补足当前条漫与游戏专题结构。[官网](https://manga.bilibili.com/)
- **限制可见**：首页直接区分免费与商业漫画，并有“下载 App，免费解锁更多章节”的提示；不能据热门作品在目录里就宣称本地可完整阅读。[官网](https://manga.bilibili.com/)
- **当前状态**：库存里被归在 novel 的 Legado 候选，但域名是漫画站；这是候选归类问题。规则需要脚本 URL，尚未适配。没有本轮图片逐页验证。
- **建议**：优先做日漫/国漫发现和公开章节评估；商业章保留权限状态。值得做，但不是“打开旧规则即可加入”的源。

### 13. 漫画柜：综合页漫价值高，质量参差要展示出来

- **覆盖与检索**：第一方分类支持地区、剧情、读者、年份、连载/完结与不同排序；日漫、港台、欧美、内地等可分开浏览。对“逛库”非常合适。[分类](https://www.manhuagui.com/list/)
- **内容质量可见证据**：更新列表中明确出现“机翻”“电子版”“卷/话”等不同版本标记，因此不能统一冠以“高清精校”。应显示版本标签，避免多版本章节乱排。[更新列表](https://www.manhuagui.com/list/update.html)

## 对设置与下一轮适配的具体影响

1. **现在能设置的源**：继续以项目已完整抽检的具体作品为依据；咚漫可作漫画公开章主入口，瓜子改作备用。番茄保留书城发现，但不能把有订阅限制的作品说成全文可读。
2. **下一批优先做的源**：小说先 SF、晋江/刺猬猫和九九藏书，各补一个明显不同的内容方向；漫画先快看与 B 漫，再评估漫画柜。不必先把七猫、书旗等相近方向同时堆进去。
3. **不应默认导入的旧条目**：书旗 shuq.net、刺猬猫错误/测试域、动漫之家旧 API、拷贝旧 H5。暂停它们是具体配置或访问证据不足，不是认定品牌内容差。
4. **合格线**：每个新适配至少选连载、完结、非首页热门各一个样本；核查目录是否完整且顺序正确、首中末章/话是否一致、订阅/锁章是否正确分类、正文无段评广告混入、图序不乱且图片真能解码。只测首章不能升为默认源。

本轮是站点内容定位和公开证据复核，未完成这 16 站的逐书全文验收，也没有做手机 WebView 的广告/弹窗视觉审计。故报告不使用“无广告”“全站高清”“永久稳定”“全部可读”等缺乏验证的标签。付费或未适配不会自动降低内容价值；错误章节、错域名、混入段评则会直接影响当前可用质量。
